거리 / 면적 / 고도 측정

측정 모드를 고른 뒤 지도를 클릭하거나, 위경도 좌표를 직접 넣어 거리와 면적을 잽니다.

측정 모드

거리·면적 모드에서 완성된 도형을 클릭하면 결과와 개별 스타일을 관리할 수 있습니다. Esc 또는 우클릭 두 번으로 현재 측정을 종료합니다. 고정 점이 거리 두 개·면적 세 개보다 부족하면 취소합니다.

지도를 자유롭게 이동합니다. 측정 기능은 꺼져 있습니다.

건물 모델

좌표 입력 측정

{"coord": [{"x": 경도, "y": 위도, "z": 높이}, ...]} 형식으로 입력합니다. 거리는 두 점부터, 면적은 세 점부터 측정됩니다.
