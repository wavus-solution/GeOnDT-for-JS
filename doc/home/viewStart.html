1. 시작하기

카메라 뷰는 메인 카메라 외의 다른 시점에서 장면을 렌더링하여 화면에 추가하는 기능입니다.
생성된 카메라 뷰는 사용자가 지정한 HTMLElement 영역에 출력됩니다.

카메라 뷰를 생성하는 방법은 두 가지입니다.
하나는 u3dApp.createView API 를 사용하는 방법이고,
다른 하나는 U3dView 객체를 직접 생성한 뒤 app에 등록 하는 방법입니다.
U3dView (opt)
opt.namestring : 카메라 뷰 이름
opt.idstring : 카메라 ID
opt.elementHTMLElement : 카메라 뷰를 출력할 HTML DOM 요소
opt.canvasStyleobject : html DOM 스타일 (css)
opt.positionGeoPosition : 현재 위치 위경도 좌표 (가변)
opt.endPositionGeoPosition : 원점 위경도 좌표.
opt.leftnumber : 카메라 뷰 좌우 각도
opt.upnumber : 카메라 뷰 상하 각도
opt.fovnumber : 카메라 뷰 시야각
opt.farnumber : 카메라 뷰 최대 거리
opt.useLineboolean : 원점과 HTML DOM 간 연결선 사용 여부
opt.useHelperObjboolean : 픽킹/편집용 가이드 객체 사용 여부
opt.objScalenumber : 가이드 객체 크기값 (기본값 : 5)
U3dApp.addView(view) : U3dApp에 카메라 뷰를 등록하는 함수
viewU3dView : 등록할 뷰
U3dApp.createView(opt) : 카메라 뷰를 생성하는 함수
optboolean : 뷰 생성 옵션 (* 위 U3dView opt 참고)
// 어댑터의 현재 활성/비활성 여부를 확인 const position = {x: 126.9404, y: 37.5183, z: 12}; const viewOpt = { name: 'camera_1, id: 'camera_1, element: $(html), canvasStyle : { height: "87%", width: "100%" } position: position, endPosition: position, left: 0, up: 90, fov: 70, far: 1000, useLine: true, useHelperObj: true, helperObjScale : 5 } // U3dApp로 뷰 생성 app.createView(viewOpt).then((view)=>{ toast('view 생성!'); }) // 또는 직접 생성 후 등록 const view = new GeOnDT.view.U3dView(viewOpt); // U3dApp 에 등록 app.addView(view).then((resolve) => { toast('view 생성!'); });

2. 조회하기

생성된 카메라 뷰는 U3dApp API getViewById 또는 getViewList로 조회할수 있습니다.
U3dApp.getViewById(id) : ID로 특정 뷰를 조회하는 함수
idstring : 카메라 뷰 ID ( view.id 값 )
return U3dView : 카메라 뷰
U3dApp.getViewList() : 전체 카메라 뷰를 조회하는 함수
return U3dView[] : 전체 카메라 뷰 목록
const id = 'camera_1'; const view = app.getViewLById(id); //또는 const viewList = app.getViewList(); const find = viewList.find((view) =>{ return view.id === id; });

3. 위치·회전 편집하기

카메라 뷰의 위치·회전를 편집하는 방법은 두 가지가 있습니다.
하나는 U3dView 클래스에서 제공하는 편집 관련 API를 사용하는 방법이며, 다른 하나는 Gizmo 툴을 사용해 조작하는 방법입니다.

먼저 U3dView 클래스에서 제공하는 편집 관련 API를 알아보겠습니다.
U3dView.setRotationUp(degUp) : 카메라 뷰 상하 각을 편집하는 함수 (회전 편집)
degUpDegree : 카메라 뷰 상하 각 (수직각)
U3dView.setRotationLeft(degLeft) : 카메라 뷰 좌우 각을 편집하는 함수 (회전 편집)
degLeftDegree : 카메라 뷰 좌우 각 (수평각)
U3dView.moveViewPosition(position) : 카메라 뷰 위치를 편집하는 함수 (위치 편집)
positionWorldPosition : 이동할 위치 좌표 (3D월드 좌표)
const view = app.getViewLById('camera_1'); // 회전 편집 view.setRotationLeft(20); view.setRotationUp(50); // 위치 편집 const position = {x: -211992.9599, y: 103254.0005, z: 17}; view.moveViewPosition(position);
Gizmo 툴은 U3dView.edit API를 통해 활성화합니다.
Gizmo 툴을 사용하려면 기준점 역할을 하는 가이드 객체(HelperObject)가 반드시 필요합니다.

useHelperObj 옵션은 기본값이 true이며, 해당 옵션이 비활성화되어 있는 경우에는 카메라 뷰 생성 시 useHelperObj: true 옵션을 명시적으로 지정해 주세요.
가이드 객체(HelperObject)는 필요에 따라 가시성을 제어할수 있습니다.
U3dView.edit(state, mode) : 카메라 뷰에 Gizmo를 추가해 편집하는 함수
stateboolean : 작업 상태 (true면 gizmo ON, false면 gizmo OFF)
modestring : 편집 모드 (translate, rotate)
U3dView.showControlObj() : 카메라 뷰의 가이드 객체 (helperObject)를 켜는(show)하는 함수
U3dView.hideControlObj() : 카메라 뷰의 가이드 객체 (helperObject)를 끄는(hide)하는 함수
const view = app.getViewLById('camera_1'); view.edit(true, 'translate'); // 이동 편집 모드 view.edit(true, 'rotate'); // 회전 편집 모드 view.edit(false); // 편집 종료

4. 카메라 설정하기

카메라 설정 API를 통해 카메라 뷰의 시야각(FOV), 최대 거리(Far), 확대 비율(Zoom), 가시선 표시 여부를 설정할 수 있습니다.
시야각(FOV)은 Field of View 약자로 카메라가 한 번에 볼 수 있는 시야각를 의미합니다.
값이 클수록 광곽, 즉 넓은 범위를 한번에 볼수 있지만 실제 객체와 출력 간의 왜곡이 발생할 수 있습니다.
값이 작을수록 망원으로, 더 좁게 보이지만 그만큼 확대되어 보이는 효과가 있습니다.
U3dView.setAngle(angle) : 카메라 뷰 FOV(카메라가 한 번에 볼 수 있는 시야각)를 설정하는 함수
anglenumber : FOV
const view = app.getViewLById('camera_1'); view.setAngle(90); // FOV 90 설정
최대 거리(far)는 카메라가 렌더링할 수 있는 최대 거리를 의미합니다.
카메라에서 얼마나 먼 거리까지 가시화할 것인지를 제어하는 핵심 파라미터입니다.
U3dView.setDistance(distance) : 카메라 뷰 최대 거리(far)를 설정하는 함수
distancenumber : 최대 거리(far)
const view = app.getViewLById('camera_1'); view.setDistance(3000); // 최대 3km까지 랜더링
Zoom은 화면에 보이는 장면의 확대·축소 비율을 제어하는 값입니다.
FOV와 달리 카메라 위치는 유지한 채 시각적 배율만 조정합니다. (세부 영역을 정밀하게 확인)
U3dView.setZoom(zoom) : 카메라 뷰 zoom을 설정하는 함수
zoomnumber : 작업 상태 (true면 gizmo ON, false면 gizmo OFF)
const view = app.getViewLById('camera_1'); view.setZoom(3); // 3배 줌
가시선은 카메라의 방향, 시야각(FOV), 거리(far) 를 3D 공간에 시각적으로 표시해주는 보조선 입니다.
필요 시 showHelper(true/false)로 표시 여부를 제어합니다.
U3dView.showHelper(visible) : 카메라 뷰 가시선을 설정하는 함수.
visibleboolean : 카메라 가시선 가시화 여부 (true면 켜고, false면 끈다.)
const view = app.getViewLById('camera_1'); view.showHelper(true); // 가시선 켜기 view.showHelper(false); // 가시선 끄기

5. 가시권 분석하기

생성된 카메라 뷰의 가시권을 분석하여, 카메라에서 실제로 보이는 영역을 3D 객체로 가시화할 수 있습니다.
가시권 분석은 U3dView.viewAnalysis API를 사용해 수행합니다.

파라미터 옵션의 type 값은 cone과 viewCone 두 가지로 설정할 수 있습니다.
viewCone은 콘 형태의 높이가 없는 평면 Mesh(2D) 로 생성되며, cone은 높이를 가진 콘 형태의 Mesh(3D) 로 생성됩니다.
U3dView.viewAnalysis(opt) : 카메라 뷰 가시권을 분석하는 함수.
optobject : 가시권 분석 객체 생성 옵션
opt.colorColor : 객체 색상
opt.opacitynumber : 객체 투명도
opt.typestring : 객체 타입 (cone, viewCone)
opt.azimuthnumber : 객체 방위각 (수평각)
opt.distancenumber : 객체 최대 거리(far)
opt.startOffsetnumber : 객체 시작 거리 (카메라 뷰와 객체 사이의 거리)
const view = app.getViewLById('camera_1'); // 가시권 분석 실행 view.viewAnalysis({ type: 'cone', color: "#fff000", opacity: 0.5, azimuth: 90, distance: 1000, startOffset : 10 }).then(()=>{ console.log('분석 성공!'); }).catch((e)=>{ console.error('분석 실패!'); });

6. 제거하기

카메라 뷰를 제거하는 방법은 U3dApp 클래스의 제거 API를 사용하는 것입니다.
removeView(view) API는 파라미터로 입력 받은 특정 카메라 뷰를 제거하고, removeAllView() API는 등록된 전체 카메라뷰를 제거합니다.
U3dApp.removeView(view) : 파라미터로 입력 받은 카메라 뷰를 제거하는 함수
viewU3dView : 제거할 뷰
U3dApp.removeAllView() : 전체 카메라 뷰를 제거하는 함수
또는 직접 U3dView에 접근해 remove() API를 호출해 제거할 수 있습니다.
U3dView.remove() : 카메라 뷰 제거 함수
// 특정 뷰 제거 const view = app.getViewLById('camera_1'); app.removeView(view); // 전체 제거 app.removeAllView(); //또는 직접 순회하면서 제거 const list = app.getViewList(); for(const view of list) { view.remove(); }
