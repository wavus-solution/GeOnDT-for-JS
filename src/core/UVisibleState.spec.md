# UVisibleState 명세

> 상태: 구현 관찰 초안

## 목적과 책임

Quadtree가 완료한 LOD 표시 단계를 타일별로 기억하고, 레이어 작업 구성이 달라졌을 때 다시 평가할 대상을 식별한다.

```spec
UVisibleState
    set(tile): 현재 활성 레이어 작업 집합이 있으면 타일의 표시 완료 상태를 기록한다.
    get(tile): 타일의 표시 완료 상태를 반환한다.
    has(tile): 타일의 표시 완료 상태 존재 여부를 반환한다.
    update(tile): 현재 활성 레이어 작업 집합이 달라졌으면 기록을 교체한다.
    delete(tile): 타일의 표시 완료 상태를 제거한다.
```

## 제약

- 상태 무효화는 실제 Scene 가시성을 변경하지 않는다.
