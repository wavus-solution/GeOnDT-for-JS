1. 시작하기

가상 건물 생성을 위해서는 먼저 app에 등록된 모드를 활성화해야 합니다.
app.getAnalysis(mode) api를 통해 등록된 모드를 가져온 후, active()를 호출하여 활성화합니다.
또는 app.activeAnalysis(mode)를 통해 바로 활성할수 있습니다.

모델 편집 모드의 이름은 CustomModel 입니다.
U3dApp.getAnalysis(analysisName) : app에 등록되 분석모드를 가져오는 함수
availablestring : 분석모드 이름
UAnalyGizmoModel.active() : 모델 편집 모드 활성 함수
UAnalyGizmoModel.deactive() : 모델 편집 모드 비활성 함수
const customModel = app.getAnalysis('CustomModel'); customModel.active(); // 모드 활성 customModel.deactive(); // 모드 비활성 // 또는 app.activeAnalysis('CustomModel'); // 모드 활성 app.deactiveAnalysis('CustomModel'); // 모드 비활성

2. 가상 건물 생성하기

가상 건물은 addCustomModel(opt) API를 통해 생성할 수 있습니다.
옵션 중 핵심 파라미터는 vertex와 extrudeheight입니다.
vertex에는 건물 바닥면을 구성하는 좌표 배열을 지정하고, extrudeheight에는 건물의 높이를 설정합니다.
UAnalyCustomModel.addCustomModel(opt) : 가상 건물을 생성하는 함수
opt.namestring : 건물 이름 (*필수)
opt.labeltextstring : 건물 라벨 텍스트
opt.extrudeheightnumber : 건물 높이 (*필수)
opt.vertexWorldPosition[] : 건물 바닥 면이 될 3D 월드 좌표 배열 (*필수)
opt.zoffsetnumber : 건물과 바닥 사이 간격
opt.colorColor : 건물 색상
opt.opacitynumber : 건물 투명도
// 가상 건물 모드 설정 const customModel = app.getAnalysis('CustomModel'); // 가상 건물 생성 옵션 설정 const opt = { name: '건물1', labeltext: '건물1', extrudeheight: 100, vertex: [ {x: -212107.8622, y: 103363.1515, z: 15}, {x: -212000.5441, y: 103244.7933, z: 15}, {x: -211887.8881, y: 103321.0438, z: 15}, {x: -211906.0493, y: 103510.4620, z: 15}, {x: -211906.0493, y: 103510.4620, z: 15} ], zoffset: 0, color: 0xffff00, opacity: 1 }; // 가상 건물 생성 customModel.addCustomModel(opt);

3. 가상 건물 조회하기

생성된 가상 건물은 getCustomModels() API로 전체 조회하거나, 가상 건물의 고유한 UID 값 또는 이름으로 조회할 수 있습니다.
UAnalyCustomModel.getCustomModels() : 전체 가상 건물 목록을 조회하는 함수
return U3dCustomModel[] : 가상 건물 목록
UAnalyCustomModel.getModelByUid(uid) : 건물 고유 ID(Uid)로 조회하는 함수
uidnumber : 조회할 가상 건물의 Uid (model.getUid() 값)
return U3dCustomModel : 해당하는 가상 건물
UAnalyCustomModel.getModelByName(name) : 건물의 이름으로 조회하는 함수
namestring : 조회할 가상 건물의 이름 (model._name 값)
return U3dCustomModel : 해당하는 가상 건물
const customModel = app.getAnalysis('CustomModel'); // 전체 가상 건물 목록 조회 const allList = customModel.getCustomModels(); // Uid로 조회 const modelByID = customModel.getModelByUid(745); // model.getUid() 값 // 이름으로 조회 const modelByName = customModel.getModelByName('건물1'); // model._name 값
생성된 가상 건물의 건축면적, 대지면적 등 영역 정보를 U3dCustomModel.getAreaValue() API를 통해 조회 가능합니다.
가상 건물의 용적률과 건폐율은 대지 면적(landArea)이 사전에 설정되어 있어야 계산할 수 있으며, 설정되지 않은 경우 기본값은 0으로 출력됩니다.

[용어 설명]
- 건축 면적 : 건물의 밑면 넓이, 제곱미터 m2
- 층 수 : (건물의 높이/3m), 3m는 통상 한 층의 높이
- 연면적 : 건물의 모든 층의 바닥면적을 합친 값
- 대지면적 : 건물을 지을 수 있도록 허가된 땅의 넓이
- 용적률 : (연면적/대지면적 X 100)
- 건폐율 : (건축면적/대지면적 X 100)
U3dCustomModel.getAreaValue() : 가상 건물의 영역 정보를 조회하는 함수
return object : 건물 영역 정보
return object.floor : 건물 층수
return object.buildingArea : 건축 면적
return object.totalArea : 연 면적
return object.landArea : 대지 면적
return object.floorAreaRatio : 건물 용적률
return object.buildingCoverageRatio : 건물 건폐율
const customModel = app.getAnalysis('CustomModel'); const model = customModel.getModelByName('건물1'); // 건물 영역 정보 추출 const info = model.getAreaValue(); console.log(info);

4. 가상 건물 편집하기

생성된 가상 건물은 제공되는 U3dCustomModel API를 통해 건물의 이름, 높이, 지면과의 거리, 라벨 텍스트를 편집할 수 있습니다.
이때, 라벨 텍스트를 변경하더라도 실제 가상 건물의 이름(_name)을 변경되지 않습니다.
U3dCustomModel.setName(name) : 가상 건물 이름을 편집하는 함수
namestring : 가상 건물 이름
U3dCustomModel.setHeight(height) : 가상 건물 높이를 편집하는 함수
heightnumber : 가상 건물 높이
U3dCustomModel.setLandHeight(landHeight) : 가상 건물 지면 높이를 편집하는 함수
landHeightnumber : 건물과 지면 사이의 높이 (Z-Offset)
U3dCustomModel.setLabelText(text) : 가상 건물 라벨 텍스트를 편집하는 함수
textstring : 라벨 텍스트
const customModel = app.getAnalysis('CustomModel'); const model = customModel.getModelByName('건물1'); // 건물의 이름 변경 ('건물1' -> '관공서1') model.setHeight('관공서1'); // 건물의 높이 변경 model.setHeight(200); // 건물과 지면과의 높이 변경 model.setLandHeight(10); // 건물 라벨 변경 model.setLabelText('관공서1');

5. 가상 건물 스타일 설정하기

가상 건물은 색상, 투명도, 텍스처 등 스타일 속성을 편집하여 실제 건물과 유사한 시각적 효과를 표현할 수 있습니다.
U3dCustomModel.setColor(color) : 가상 건물에 색상을 설정하는 함수
colorColor : 색상
U3dCustomModel.setOpacity(opacity) : 가상 건물에 투명도를 설정하는 함수
opacitynumber : 투명도 (0~1)
U3dCustomModel.setTexture(textureUrl) : 가상 건물에 이미지 텍스처를 설정하는 함수
textureUrlstring : 텍스처 위치 (URL)
const customModel = app.getAnalysis('CustomModel'); const model = customModel.getModelByName('관공서1'); // 건물 색상 변경 model.setColor("fff000"); // 건물 투명도 변경 model.setOpacity(0.7); // 이미지 텍스처 설정 const textureUrl = './image/buld/buld_texture_1.jpg'; model.setTexture(textureUrl);

6. 가상 건물 병합하기

두 개 이상의 가상 건물은 하나의 가상 건물 객체로 병합할 수 있습니다.
UAnalyCustomModel.merge API를 통해 병합된 건물의 생성 파라미터를 생성한 뒤, 해당 파라미터를 사용해 하나의 병합된 가상 건물을 생성합니다.
UAnalyCustomModel.merge(name, meshBase, meshes, useDelete) : 가상 건물을 하나의 건물로 병합하는 함수
namestring : 병합 건물 이름
meshBaseU3dCustomModel : 병합 기준이 될 건물
meshesU3dCustomModel[] : 기준이 될 건물과 병합 할 건물 목록
useDeleteboolean :기존 건물 삭제 여부
const customModel = app.getAnalysis('CustomModel'); const models = customModel.getCustomModels(); const baseModel = models[0]; // 병합된 가상 건물 생성 파라미터 가져오기 const param = customModel.merge('병합1', baseModel, models, true); // 병합 객체 생성 customModel.addCustomModel(param);

7. 가상 건물 삭제하기

생성한 가상 건물은 UAnalyCustomModel 클래스에서 제공하는 제거 관련 API를 사용해 삭제할 수 있습니다.
전체 건물을 한 번에 제거하거나, 파라미터를 지정해 특정 건물만 선택적으로 제거할 수 있습니다.
UAnalyCustomModel.removeAll() : 생성된 전체 가상 건물을 제거하는 함수
UAnalyCustomModel.removeModel(model) : 파라미터로 입력된 가상 건물을 제거하는 함수
modelU3dCustomModel : 가상 건물 객체
UAnalyCustomModel.removeModelByUid(uid) : Uid를 통해 해당하는 가상 건물을 제거하는 함수
uidnumber : 가상 건물 Uid
const customModel = app.getAnalysis('CustomModel'); const model = customModel.getModelByName('관공서1'); // uid가 745인 가상 건물만 제거 customModel.removeModelByUid(745); // 파라미터로 model 객체를 넣어 제거 customModel.removeModel(model); // 전체 제거 customModel.removeAll();
또는 직접 가상 건물 객체에 접근해서 U3dCustomModel.dispose() API로 제거할 수 있습니다.
U3dCustomModel.dispose() : 가상 건물 제거 함수
const customModel = app.getAnalysis('CustomModel'); const model = customModel.getModelByName('관공서1'); // 객체를 직접 참조해 제거 model.dispose();
