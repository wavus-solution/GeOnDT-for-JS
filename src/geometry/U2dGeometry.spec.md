# U2dGeometry 명세

> 상태: 구현 관찰 초안

## 목적과 책임

점·선·면 도형의 원본 OpenLayers Feature를 편집하는 공통 인터페이스다. 셰이더 geometry와 타일 자원은 소유하지 않는다.

## 공개 계약

- 기본 생성자는 이름·좌표·채움·외곽선·검색 제외·편집 잠금·표시 상태를 준비하고 하위 클래스의 `createGeometry()`를 호출한다. `sourceFeature`로 전체 원본을 전달하면 기존 Feature와 geometry를 그대로 빌리며 빈 형상·기본 OL 스타일은 생성하지 않는다.
- `getFeature()`는 원본 OpenLayers Feature를 반환한다. `setFeature()`는 기존 Feature의 형상·속성·스타일을 보존하며 스타일이 없는 원본에만 도형의 기본 스타일을 연결한다. 매개체를 전달하면 원본 OpenLayers Feature를 해석할 수 있어야 한다. 레이어 연결 중 다른 Feature로 교체하면 기존 원본을 변경·해제하기 전에 오류로 거부한다. 동일 원본의 소유권 지정은 유지하며, 분리 후에는 다른 원본을 연결할 수 있다.
- `getGeometry()`는 현재 원본의 geometry를 반환한다. 형상 참조가 교체되면 기존 미리보기를 종료하고 확정 좌표를 새 원본에 맞춘다. 조회와 순차 입력은 이 경로를 사용하여 이전 좌표로 교체 원본을 덮어쓰지 않는다. 내부 생성 스타일은 초기 geometry에 고정하지 않고 Feature의 현재 형상을 사용한다. 외부에서 연결한 Feature의 해제 책임은 원래 소유자에게 있다.
- `setPosition(position, srs)`는 전체 좌표를 바꾼다. 기본 좌표계는 EPSG:3857이고 EPSG:4326도 지원한다. 다른 좌표계는 변경 전에 오류로 거부한다. 하위 클래스의 기존 기본 좌표계는 유지한다.
- `getPosition()`은 현재 원본 좌표를 반환하며 순차 입력의 확정 좌표를 덮어쓰지 않는다. 반환 배열의 수정은 `setPosition()`으로 반영한다. 임시 미리보기를 조회해도 다음 `addPosition()`의 확정점에 포함되지 않는다. 명시적인 형상 설정·변환 뒤 확정 좌표를 맞추는 동작은 `_syncCoordinates()`가 담당한다.
- `translate(x, y)`는 지도 좌표 단위로 이동한다. `rotate(angle, anchor)`는 라디안 단위의 반시계 회전이며, 기준점 생략 시 경계 상자 중심을 쓴다. `scale(x, y, anchor)`는 지도 좌표에서 크기를 바꾸며 y 생략 시 x를 사용한다.
- `addPosition()`과 `setLastCoordinate()`는 순차 입력과 임시 마지막 점을 제공한다. 미리보기 중 이동·회전·크기 변경은 확정점과 임시점을 함께 변환하되 확정점 수를 늘리지 않는다. `addPosition()`·`setPosition()` 또는 다른 Feature의 `setFeature()`가 성공하면 기존 임시점을 종료한다. `buildCoordinates()`는 하위 클래스별 좌표 포장을 담당한다. `transformPoint()`는 기존 위경도·지도 좌표 변환을 제공한다.
- 원본 채택 경로의 편의 스타일 편집은 OL 리소스 없이 기존 원본의 `_style`에 명시적으로 바꾼 항목만 기록한다. `getStyle()`은 첫 조회에서 저장된 명시 색·두께·투명도·표시 상태를 OL Style과 편의 필드에 함께 반영한 뒤 재사용한다. 지연 스타일의 원형 이미지를 직접 교체하면 이미지의 채움·외곽선을 우선하여 편의 필드와 원본 편집값을 함께 동기화하고, 모두 없는 항목은 표시 상태에서만 불투명도 0으로 계산하고 원본 편집값에는 저장하지 않는다. 채움·외곽선을 복원하면 현재 색상 알파나 상속값으로 돌아가며 사용자가 명시한 불투명도 0은 유지한다. 조회만으로 원본의 미지정 스타일을 기본값으로 덮어쓰지 않는다.
- `setStyle()`과 편의 스타일 편집은 단일 OpenLayers Style을 기준으로 한다. Style 배열·함수 평가와 다중 스타일 합성은 지원 범위에 포함하지 않는다. `setFillColor()`·`setStrokeColor()`·`setStrokeWidth()`는 원본 스타일과 편의 필드를 함께 갱신한다. 원본 스타일이 외부에서 교체되어도 현재 채움·외곽선을 대상으로 수정한다. 명시적으로 지정한 스타일의 별도 형상 설정은 보존한다. 공개 스타일 setter는 기존 `_isSetStyle` 표식으로 명시 편집임을 알린다. 이전 전역값과 같은 값을 다시 지정해도 개별 편집으로 반영하며 형상 이동만으로 개별 스타일을 만들지 않는다.
- `getParam()`은 원본의 현재 채움·외곽선 색/불투명도·두께·표시·검색 제외·잠금·연결된 라벨 표시를 반환한다. 미지정 스타일은 undefined이며 조회로 OL 자원을 만들거나 레이어 상속값을 고정하지 않는다. `setParam()`은 null·undefined를 제외한 항목만 적용하고 모든 입력을 검증한 뒤 변경한다. 좌표·절대 회전·배율·이름·메타데이터는 포함하지 않는다. 좌표와 변환은 기존 API로 편집한다.
- `getFillColor()`·`getStrokeColor()`·`getStrokeWidth()`와 `getFillOpacity()`·`getStrokeOpacity()`는 현재 원본의 단일 스타일을 읽는다. 원형 이미지의 채움·외곽선을 우선하며 숨김/강조 중에는 원래 편집 스타일을 읽는다. 불투명도는 별도 지정값이 RGBA·HSLA 색상 알파보다 우선하며 HSLA의 색상 자체는 유지한다. `setFillOpacity()`·`setStrokeOpacity()`는 0~1 범위를 검증하고 변경을 자동 통지한다.
- `setParam({nonChanged:false,...})`는 잠금을 먼저 해제하고 편집한다. true는 이번 편집 후 잠근다. 잠금 중 스타일/반경 변경은 무시하며 표시·검색 제외·라벨 상태는 별도로 변경한다.
- `getProperties()`는 현재 형상 속성을 제외한 사용자 속성의 얕은 복사본을 반환한다. `setProperties(object|string)`는 JSON 깊은 복사 뒤 전체 교체하며 형상 속성/Feature ID는 보존한다. 잘못된 JSON·순환 참조·예약 키 __proto__는 기존 속성을 지우기 전에 거부한다. `addProperties()`는 없는 키만, `changeProperties()`는 있는 키만 편집하고 `removeProperties()`는 해당 사용자 키만 제거한다. null·undefined 값의 추가/변경은 무시한다. 기존 `setMeta()`의 병합과 `getMeta()`의 형상 포함 반환은 유지한다.
- `setShowLabel()`·`getShowLabel()`은 현재 연결된 라벨의 visible 상태를 사용한다. 기존 `showLabel()`·`hideLabel()`도 같은 경로를 쓴다. 라벨이 없으면 false이며 이후 연결할 라벨의 희망 상태를 별도 저장하지 않는다.
- `nonChanged`는 스타일 편집을 제한한다. 설정과 해제 모두 원본 변경으로 통지한다. 검색 제외도 설정·해제 모두 원본에 반영한다.
- `hide()`는 최신 원본 단일 스타일을 보관한 뒤 표시 상태가 false인 스타일을 적용하며 `show()`는 보관한 스타일로 복원한다. 숨김은 검색 제외와 별개다.
- 이름 조회·수정, 사용자 속성 조회·저장, 경계 중심 조회와 라벨 연결·조회·표시·해제는 기존 기능을 유지한다.
- `dispose()`는 중복 호출에 안전하며 소유 연결의 해제 통지 후 소유 Feature·geometry와 좌표·메타데이터를 정리한다. 외부 Feature는 파괴하지 않는다. `setFeature(feature, true)`로 내부 생성 원본의 해제 책임을 명시적으로 넘길 수 있으며, 같은 원본을 다시 연결해도 기존 소유권을 해제하지 않는다.

## 연결과 검증

강조 상태는 피처 매개체에서 관리하며 도형에 레이어 연결 목록을 추가하지 않는다. 원본 Feature의 강조 표시를 편집 상태에 섞지 않는다.

원본 변경의 타일 반영은 `U2dVectorShaderLayer`의 등록된 연결이 담당한다. 같은 원본의 중복 등록은 구독을 추가하지 않으며, 레이어에서 분리하거나 도형을 해제하면 구독을 제거한다.

`tests/geometry/vector-binding.test.mjs`에서 원본 동일성, 좌표·스타일 변경, 변환, 검색 제외, 잠금, 중복 등록과 해제를 확인한다. 실제 지도 GPU 픽셀은 이 검증에 포함하지 않는다.

`tests/geometry/vector-param.test.mjs`에서 파라미터 부분 적용·입력 검증·미지정 스타일 보존·다중점 공통 반경·투명도·사용자 속성/형상 보존·라벨 호환을 검증한다. `sample-viewer/u2dGeometryCheck.html`에서 파라미터·투명도 복원과 사용자 속성 편집을 일괄 확인한다.
