1. 시작하기

* ImageLayer를 시작하기 위해서 우선 생성 옵션 값이 필요합니다. 옵션 값의 자세한 내용은 API 페이지의 ImageLayer를 카테고리를 참고해 주세요.
* 생성 옵션 값 중 url은 꼭 넣어 줘야하는 필수 옵션 값입니다.
const option = { name : "emapsat", // 레이어 이름 baseurl : "http://210.117.198.120:8081/o2map/services", // 이미지 데이터 URL *필수 입력 reverseY : true, // Y축 반전 여부, default 'false' useProxy : true, // 프록시 사용 여부, default 'false' xyorder : "xy", // Col Row 순서, default 'xy' transparent: false // layer 투명화 여부 default 'false' }
* 자주 사용되는 Emap base와 Emap satellite 이미지 레이어는 app.createEmapBaseLayer(opt), app.createEmapSatLayer(opt) 함수를 사용해 생성합니다.
const emapBaselayer = app.createEmapBaseLayer(option); // Emap Base 이미지 레이어 생성 const emapSatlayer = app.createEmapSatLayer(option); // Emap Satellite 이미지 레이어 생성
* 그외 ImageLayer는 new GeOnDT.image.U3dImageXYZLayer(opt) 객체 생성 후 app.addLayer() 함수를 호출하여 생성합니다.
const layer = new GeOnDT.image.U3dImageXYZLayer(option); app.addLayer(layer); //app에 생성한 layer를 등록
* 모든 레이어 객체는 생성 후 .ready() 또는 .then() 을 포함하는 promise 함수를 지원합니다. 해당 함수를 이용해 후처리를 수행할 수 있습니다.
layer.ready(() => { console.log(name + " create success."); }).then(() => { console.log(name + " create success."); }).catch(function (e) { console.error("work fail : " + e); }).finally(() => { console.log(name + " create end."); });
* 생성된 레이어는 app.showLayer(layername, true/false) 함수를 통해 가시화/비가시화가 가능합니다.
layer.ready(() => { app.showLayer(name, true).then(()=>{ console.log(name + " show."); }); }).catch(function (e) { console.error("work fail : " + e); });
