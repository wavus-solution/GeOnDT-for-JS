1. 시작하기

거리·면적·고도 측정을 사용하려면 먼저 app에 등록된 해당 모드를 활성화해야 합니다.
app.getAnalysis(mode) API로 등록된 모드를 가져온 뒤 active()를 호출하여 활성화할 수 있습니다.
또는 app.activeAnalysis(mode) API를 사용하면 모드를 바로 활성화할 수 있습니다.
측정 모드는 활성화된 상태에서 화면을 클릭하여 수행하고, 더블 클릭해 완료합니다.

Distance : 거리 측정 모드 이름.  Area : 면적 측정 모드 이름.  Height : 고도 측정 모드 이름.
const analysis = app.getAnalysis('Distance'); if(analysis) analysis.active(); // 모드 활성 if(analysis) analysis.deactive(); // 모드 비활성 // 또는 app.activeAnalysis('Distance');
const analysis = app.getAnalysis('Area'); if(analysis) gizmo.active(); // 모드 활성 if(analysis) gizmo.deactive(); // 모드 비활성 // 또는 app.activeAnalysis('Area');
const analysis = app.getAnalysis('Height'); if(analysis) analysis.active(); // 모드 활성 if(analysis) analysis.deactive(); // 모드 비활성 // 또는 app.activeAnalysis('Height');

2. 좌표로 측정하기

거리·면적 측정 모드는 기본적으로 화면 클릭 인터랙션을 통해 수행되지만, 측정할 위·경도 좌표 정보가 있는 경우 좌표를 직접 입력하여 측정할 수도 있습니다.
좌표를 이용해 거리를 측정하는 API는 drawDistance(points), 면적을 측정하는 API는 drawArea(points)입니다.
UAnalyDistance.drawDistance(points) : 좌표로 거리를 측정하는 함수
pointsGeoPosition[] : 위경도 좌표 리스트
const analysis = app.getAnalysis('Distance'); points = [{x: 126.9395, y: 37.52, z: 8.145}, {x: 126.939, y: 37.519, z: 15}, {x: 126.94, y: 37.519, z: 15}]; // 좌표 거리 측정 analysis.drawDistance(points);
UAnalyArea.drawArea(points) : 좌표로 면적을 측정하는 함수
pointsGeoPosition[] : 위경도 좌표 리스트
const analysis = app.getAnalysis('Area'); points = [{x: 126.9395, y: 37.52, z: 8.145}, {x: 126.939, y: 37.519, z: 15}, {x: 126.94, y: 37.519, z: 15}]; // 좌표 면적 측정 analysis.drawArea(points);

3. 측정 스타일 설정

측정 모드는 U3dShaderMeasureLayer 위에 측정 영역을 그려 표시합니다.
측정 스타일을 변경하려면 U3dShaderMeasureLayer의 setStyle(opt) API를 사용하여 설정할 수 있습니다.
측정 스타일은 모든 측정 영역에 일괄 적용됩니다.
U3dShaderMeasureLayer.setStyle(opt) : 좌표로 면적을 측정하는 함수
optobject : 측정 스타일 옵션 opt.fillColorobject : 측정 영역 색상 opt.opacityobject : 측정 영역 투명도 opt.strokeColorobject : 측정 영역 테두리 색상 opt.strokeWidthobject : 측정 영역 테두리 두께
const measureLayer = app.getMeasureLayer(); // 측정 스타일 정보 생성 const styleOpt = { fillColor : 'rgb(255,170,0)', opacity: 0.5, strokeColor : '#fff000', strokeWidth : 5 } // 측정 스타일 설정 measureLayer.setStyle(styleOpt);
