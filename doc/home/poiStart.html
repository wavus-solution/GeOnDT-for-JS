1. 생성하기

POI(Point of Interest) 는 지도상의 특정 좌표에 이미지나 텍스트 형태의 마크를 표시하는 기능입니다.
new GeOnDT.geom.U3dPOI(opt)로 POI를 생성한 뒤, U3dApp.addPOI(poi) API를 호출하여 화면에 등록·출력합니다.
GeOnDT.geom.U3dPOI (opt)
opt.positionstring : POI 위치 (필수)
opt.namestring : POI 식별 이름
opt.colorstring : POI 색상
opt.imagestring : POI 이미지 라벨
opt.imageSizestring : POI 이미지 라벨 사이즈 (기본 20)
opt.labelstring : POI Text 라벨
opt.sizestring : POI Text 라벨 폰트 사이즈
U3dApp.addPOI(poi ) : app에 생성한 POI를 등록하는 함수.
poiU3dPOI : 등록할 POI
const worldPos = {x: -212028.5067, y: 103227.2844, z: 15} // 3D 월드 좌표 // POI 객체 생성 const poi = new GeOnDT.geom.U3dPOI({ position: worldPos, image: 'image/marker.png', label: 'POI Test' }); app.addPOI(poi); // app에 POI 등록

2. 조회하기

U3dApp에 등록된 POI 객체는 배열 형태로 저장되며, U3dApp.getPoiList() API를 통해 해당 배열을 조회할 수 있습니다.
또한 POI의 고유 id를 사용해 U3dApp.getPoiById(id) API로 특정 POI를 조회할 수 있습니다.
U3dApp.getPoiList() : app에 등록된 전체 POI를 조회하는 함수.
U3dApp.getPoiById(id ) : ID로 특정 POI를 조회하는 함수.
idstring : 조회할 POI ID
const poiList = app.getPoiList(); // 전체 POI 조회 for(let i=0; i< poiList.length; i++) { const poi = poiList[i]; console.log( `${i}번 POI ID : ${poi.uuid}` ); } const id = poiList[0].uuid; const poi = app.getPoiById(id); // 배열의 첫번째 POI 조회

3. 관리하기

POI가 많아질수록 메모리 부하가 증가하므로, 적정 수준으로 관리하는 것이 중요합니다.
그룹 단위로 묶어 가시화 레벨을 제어하거나, 현재 화면에 보이는 POI만 출력하는 등 다양한 관리 방식이 있습니다.

핵심은 POI를 매번 생성·제거하지 않는 것입니다.
초기에 인스턴스화한 POI를 재사용하고, 가시성(visible)을 제어하는 방식이 성능 측면에서 가장 효율적입니다.

POI의 가시성을 제어하는 방법은 U3dApp의 API를 쓰는 방법, 직접 U3dPOI 객체를 제어하는 방법 두가지가 있습니다.
U3dApp.showPOI( isShow, poi ) : 파라미터로 입력받은 특정 POI 가시성 제어 함수
isShowboolean : 가시화 여부 poiU3dPOI : 대상 POI
U3dApp.showAllPOI( isShow ) : 전체 POI 가시성 제어 함수
isShowboolean : 가시화 여부
const poi = app.getPoiById(id); app.showPOI(true, poi); // 가시화 true app.showPOI(false, poi); // 가시화 false //또는 전체 POI 가시성 제어 app.showAllPOI(true); // 가시화 true app.showAllPOI(false); // 가시화 false
U3dPOI.show() : POI 가시화(show) 함수
U3dPOI.hide() : POI 비가시화(hide) 함수
const poi = app.getPoiById(id); poi.show(); // 가시화 true poi.hide(); // 가시화 false
응용하면 POI가 화면에 표출될 때만 가시성을 활성화하고, 표출되지 않을 경우에는 가시성을 비활성화하여 메모리 사용을 절약할 수 있습니다.
app.setRenderBefore('frustumCheck', frustumCheck); function frustumCheck () { const frustum = app._frustum; const poiList = app.getPoiList(); if(!frustum) return; for(let poi of poiList) { const geo = poi.getPosition(); const pos = app.geographicToVector3(geo); // 카메라 프러스텀에 POI가 포함되는지 확인 if(frustum.containsPoint(pos)) { poi.show(); } else { poi.hide(); } } }

4. 제거하기

U3dApp에 등록된 POI는 U3dApp.removeAllPOI()로 전체 제거할 수 있으며, U3dApp.removePOI(poi) API를 사용해 특정 POI만 선택적으로 제거할 수 있습니다.
U3dApp.removeAllPOI() : app에 등록된 전체 POI를 조회하는 함수.
U3dApp.removePOI(c) : 특정 POI를 제거하는 함수.
poiU3dPOI : 제거할 POI
// POI 전체 제거 app.removeAllPOI(); // 또는 직접 순회하면서 하나씩 제거 const poiList = app.getPoiList(); // 전체 POI 조회 for(const poi of poiList) { app.removePOI(poi); }
