SHP 모델 레이어 예제

Shp 파일을 업로드하여 3D 모델을 생성하는 레이어 예제입니다.
생성한 3D 모델의 색상, 투명도, 외벽 텍스쳐 이미지 스타일을 설정할수 있습니다. 

지도상에 설계건물(shp 파일)을 추가할 수 있습니다.
        1. 설계건물(shp) 추가 버튼 클릭
        2. 파일 목록창에서 shp파일 셋(shp, prj, dbf)을 선택합니다.
            * shp파일이 선택되지 않으면 건물이 로드되지 않습니다.
            * shp파일 셋(shp, prj, dbf)은 같은 이름이여야 합니다.
            * prj 파일이 없을 경우 EPSG:5179 좌표로 로드 됩니다.
        3. 저장버튼을 클릭하면 현재 로드된 설계건물이 저장됩니다.
        4. 불러오기 버튼은 저장된 설계건물을 불러옵니다.
        5. 전체지우기 버튼은 현재 로드된 모든 설계건물을 삭제합니다.
        6. 건물색상 지정은 [선택] 버튼 클릭 후에 대상을 지정 후에 단일 및 전체 적용으로 설정할 수 있습니다.
        7. 건물 텍스처 변경은 [선택] 버튼 클릭 후에 대상을 지정 후에 텍스트 이미지 파일을 불러 적용합니다.
        8. 라벨 적용은 [선택] 버튼 클릭 후에 대상을 지정 후에 [라벨적용]버튼을 클릭하여 적용합니다.
