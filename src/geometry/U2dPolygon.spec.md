# U2dPolygon 명세

> 상태: 구현 관찰 초안

## 목적과 책임

면의 전체 원본을 공통 도형 인터페이스로 편집하고 외곽선·내부 구멍·복합 면의 구조를 보존한다.

## 공개 계약

- 생성자는 기본 면 도형을 준비하고 `createGeometry()`는 OpenLayers MultiPolygon을 최초 생성한다.
- `setPosition()`은 단일 링, 링 목록 또는 폴리곤 목록을 받는다. 기본 입력 좌표계는 EPSG:4326이며 EPSG:3857도 지원한다.
- 각 링의 첫 점과 마지막 점이 다르면 첫 점을 덧붙여 닫는다. 입력 좌표의 모든 링과 폴리곤을 변환하며 첫 외곽선만 남기지 않는다.
- 연결된 Polygon 원본에 단일 면을 적용할 때는 원본 geometry를 유지한다. 복합 면이 필요하면 MultiPolygon으로 반영한다.
- `getPosition()`은 단일 외곽선이면 링, 구멍이 있으면 링 목록, 여러 면이면 폴리곤 목록을 반환하며 조회만으로 확정 좌표를 변경하지 않는다. 같은 좌표계를 명시하여 다시 `setPosition()`에 전달해도 전체 형상을 보존한다. 단일 외곽선의 설정·변환 후에는 `_syncCoordinates()`가 마지막 닫힘점을 확정 좌표에서 제외하여 후속 순차 입력에 중복 삽입하지 않는다. 변환된 미리보기 점도 확정점에서 제외하고 별도로 보관한다.
- 순차 입력은 첫 폴리곤의 외곽선에 점을 추가한다. `buildCoordinates()`는 원본의 Polygon·MultiPolygon 타입과 내부 구멍·나머지 폴리곤을 보존한다. `getCenter()`와 `getArea()`는 현재 원본에서 경계 상자 중심과 지도 좌표 단위의 면적을 계산하므로 외부 형상 교체 직후에도 최신 결과를 반환한다.

## 검증

`tests/geometry/vector-binding.test.mjs`에서 구멍을 포함한 원본의 왕복 설정, 내부 구멍 검색 제외와 terrain의 외곽선·구멍 그룹 보존을 확인한다. 실제 지형 합성 픽셀은 별도 검증 대상이다.
