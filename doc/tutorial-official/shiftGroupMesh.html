사용자 지정 그룹 이동 설정 예제

사용자가 지정한 그룹의 위치를 설정하거나 추가된 사용자 지정 그룹들의 사이 간격을 설정 하여 위치를 조정할수 있습니다.
Animation 시간 설정을 따로 지정하여 설정한 위치까지의 이동 동작을 확인할 수 있습니다. 


    [전체 사용자 지정 그룹 위치 설정]에서 값들을 변경시 목록에 포함된 그룹들의 위치를 설정한 간격만큼 이동시킵니다.
    목록에 가장 처음에 추가된 그룹을 기준으로 위치를 이동합니다.
    [Animation 시간 설정] 해당 시간 설정은 [전체 사용자 지정 그룹 위치 설정]에서 설정한 위치까지 이동 시간을 설정합니다.
    사용자 지정 그룹 목록에서 [이동] 버튼을 클릭시 그룹에 해당하는 Mesh들의 위치를 설정한 값으로 이동 시킵니다.
