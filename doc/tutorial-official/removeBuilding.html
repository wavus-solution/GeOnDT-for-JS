건물 지우기

         #건물 선택 방식
         1. 클릭으로 선택 : 건물을 클릭해 선택하는 방식으로, Shift 키를 누른상태로 클릭할 경우 다중 선택을 지원합니다.
         2. 영역으로 선택 : 지표면에 마우스 클릭으로 영역을 그려 해당 영역안에 포함되는 건물을 선택하는 방식입니다.

         #건물 선택
         건물 선택 방식을 선택한 뒤, 지도상에서 마우스 클릭을 통해 건물을 선택합니다.
         선택된 건물정보는 '선택된 건물 목록' 에서 확인 할 수있습니다.

         #선택된 건물 지우기
         '선택된 건물 지우기' 버튼을 클릭하게 되면 선택된 건물이 지도상에서 제거 됩니다.
         삭제된 건물은 '삭제건물 목록'에서 확인 할 수 있습니다.

         #건물 지우기 취소
         '삭제건물 목록'에서 항목마다 '건물 지우기 취소' 버튼을 통해 건물 지우기를 취소 할 수있습니다.
         해당 버튼을 클릭하면 삭제되었던 건물이 다시 가시화 됩니다.

         #전체 지우기 취소
         '전체 지우기 취소' 버튼을 클릭해 모든 지우기 작업을 취소 할 수 있습니다.

         #저장
         '저장' 버튼을 클릭해 현재 작업 내용을 저장 할 수 있습니다.
         저장 포멧은 JSON 형태로 저장됩니다.
         예제 페이지에서는 javascript에 SAVE_REMOVED_INFO 변수로 저장합니다. 콘솔에서 확인 할 수 있습니다.

         #불러오기
         '불러오기' 버튼을 클릭해 저장되었던 지우기 작업 내역을 로딩할 수 있습니다.
         예제 페이지에서는 javascript에 SAVE_REMOVED_INFO 변수로 저장된 내역을 사용합니다.
