1. 최대 프로세스 수 설정

한 프레임당 작업할 최대 프로세스 수를 설정할 수 있습니다.
app 생성 시 maxprocess 옵션 값을 추가하거나, U3dApp 함수 setMaxProcess()를 사용해 설정합니다.
최대 프로세스 수가 클수록 연산 처리 성능은 빨라지지만, 메모리 부하나 UI 반응 속도 저하 등의 문제가 발생할 수 있으므로 적절히 조절해야 합니다.

** 별도로 설정하지 않는 경우 사용자의 컴퓨터 성능에 따라 자동으로 조정됩니다. **
U3dApp.setMaxProcess(count) : 한 프레임당 작업할 최대 프로세스 수를 설정하는 함수
countnumber : 최대 프로세스 수
// app 생성 시 옵션 값으로 지정 const app = new GeOnDT.U3dAPP({ containername: 'map', maxprocess: 12 }); // 또는 setMaxProcess 함수 사용 app.setMaxProcess(12);

2. 텍스쳐 보정 설정

텍스처 보정 값은 화면에 출력되는 텍스처 품질을 조절할 때 사용합니다.
app 생성 시 improveTexture 옵션 값을 추가하거나, U3dApp 함수 setImproveValue()를 사용해 설정합니다.
보정 값을 높이면 텍스처 품질은 좋아질 수 있지만, 사용 환경에 따라 성능 부담이 생길 수 있으므로 상황에 맞게 조절하는 것이 좋습니다.
U3dApp.setImproveValue(value) : 텍스처 보정 값을 설정하는 함수
valuestring : 텍스처 보정 값 (예: 'high')
// app 생성 시 옵션 값으로 지정 const app = new GeOnDT.U3dAPP({ containername: 'map', improveTexture: 'high' }); // 또는 setImproveValue 함수 사용 app.setImproveValue('high');
