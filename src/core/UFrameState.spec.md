# UFrameState 명세

> 상태: 구현 관찰 초안

## 목적과 책임

Quadtree 자식의 비동기 작업을 모으고, 완료된 부모·자식 LOD 표시 상태를 Frame 단위로 전환한다.

```spec
UFrameState
    addUpdate(tile, force):
        호출마다 독립된 workInfo Map과 최종 작업 배열을 만든다.
        비동기 실행에 전달되는 이 두 객체는 다른 수집에서 재사용하지 않는다.
        자식 레이어 작업을 수집하고 실행한다.
    setWork(force, workInfo):
        부모의 네 자식 모두를 순회하며 passLevel 이상인 자식의 영상·고도 작업을 수집한다.
        현재 setWork 호출에서만 소유하는 빈 배열 하나를 만든다. 이 배열은 작업을 담지 않으며 표준 수집의 빈 결과에서만 공유한다.
        실행기에 _getTerrainWork가 있으면 자식·force·부모·빈 결과용 배열로 호출한다.
            표준 getWork이면 첫 작업이 생길 때 독립된 결과 배열을 만들고, 작업이 없을 때만 빈 배열을 공유한다. 인스턴스·prototype 재정의는 기존 다섯 인수와 수신자로 호출한다.
        이 내부 메서드가 없는 외부 실행기는 getWork에 자식·force·undefined·undefined·부모를 전달한다.
        영상·고도 수집을 모두 마친 뒤 영상부터 필터링하고 최종 작업 목록에 추가한다.
            고도 수집 훅이 영상 반환 배열이나 완료 기록을 변경하면 필터링은 변경 후 상태를 사용한다.
            외부 실행기의 반환 배열은 비우거나 재사용하지 않는다.
        표준 실행기는 완료 검사를 작업 객체 생성 전에 적용하여 즉시 버릴 작업의 생성을 생략한다.
        새 인수를 사용하지 않는 외부 실행기도 지원하도록 기존 수집 후 검사를 유지한다.
            영상 완료 기록이 있으면 isTileWorkComplete를 먼저 조회하고 getCache를 조회한다.
            자체 완료가 엄격한 true이거나 캐시가 truthy이면 건너뛰며 그 밖에는 완료 기록을 지운 뒤 수집한다.
            고도 완료 기록이 있으면 건너뛴다.
        수집된 전체 개수와 force를 workInfo에 기록하고 부모의 갱신 시각을 설정한다.
    finishWork(tile, work, force): 자식 작업 완료 상태를 반영하고 LOD 표시 전환을 다시 시도한다.
    setVisibleTile(tile):
        처음 완료된 부모는 모든 자식 표시가 성공한 뒤 숨긴다.
        자식들의 부착 호출 뒤 네 직계 자식의 표시 준비를 다시 검사한다.
            표준 타일은 _getPresentationSummary로 상세 배열 없는 집계를 사용한다.
            getPresentationSnapshot 재정의는 타일의 집계 메서드가 기존 receiver와 무인수 호출로 보존한다.
            집계 메서드가 없는 객체는 기존 getPresentationSnapshot을 사용한다.
            전환 준비가 완료되었거나 허용된 기존 표시가 부착되어 있고 안전할 때만 해당 자식이 준비된 것으로 판정한다.
        자식 표시가 실패하면 부모를 표시하고 이미 표시한 자식을 숨긴다.
        완료 기록 뒤 작업 구성이 바뀌면 자식의 현재 표시 상태만 다시 적용한다.
        유효한 자식 Presentation 위로 숨은 부모를 다시 표시하지 않는다.
    finishWork(tile, work, force):
        부모에 묶인 모든 자식 작업이 끝나면 표시 전환을 시도한다.
```

## 제약

- 자식 하나라도 표시할 수 없으면 해당 전환을 완료 상태로 기록하지 않는다.
- 완료 기록이 있는 상태의 재평가에서는 부모의 숨김 상태를 유지한다.
