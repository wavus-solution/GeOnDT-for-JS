DXF 모델 레이어 예제

DXF 파일을 업로드하여 3D 모델을 생성하거나 2D 평면 이미지를 생성하는 레이어 예제입니다.
생성한 3D 모델의 색상, 투명도, 외벽 텍스쳐 이미지 스타일을 설정할수 있습니다. 

평면도, 구역도(dxf) 가시화
        1. 평면도 또는 구역도 dxf 추가 버튼 클릭
        2. 해당되는 dxf 파일을 선택하면 지도상에 가시화 됩니다.
            * 기본 좌표계는 EPSG:5179 입니다.
        3. 각 목록창에서 현재 가시화된 레이어를 저장 및 불러오기, 전체 지우기 기능을 제공합니다.
