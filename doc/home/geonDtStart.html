1. 시작하기

  • GeOnDT.js를 시작하기 위해서는 당사의 인증 서버를 통해 라이센스 인증을 받거나 오프라인 라이센스를 발급받아 합니다.
  • GeOnDT.js 스크립트를 로드하기 전에, 발급된 license.js를 먼저 로드하면 자동으로 라이센스 인증 기능을 수행합니다.
  • 이전 버전의 Union3D 명칭을 사용해도 되지만 현 명칭인 GeOnDT 사용을 권장합니다.
  • Script 호출시 id 태그에 "GeOnDT"를 선언하여 호출 하는 것을 권장합니다.
  • .ready()나 .then()을 사용해 GeOnDT가 잘 호출 되었는지 확인 후 U3dApp API를 생성합니다.
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>GeOnDT</title> </head> <body> <div id="map"></div> <script src="../dist/license.js" charset="utf-8"></script> <!-- 인증을 위한 license.js 로드 --> <script id="GeOnDT" src="../dist/GeOnDT.min.js"> </script> <!-- GeOnDT min.js 로드 --> <script> GeOnDT.ready(function () { const app = new GeOnDT.U3dAPP({ containername: 'map', //+ U3dApp(지도영역)의 div ID, *필수 입력 }); }); </script> </body> </html>

2. 시작 위치 설정

app을 생성했다면, setHomePosition 함수를 통해 카메라가 최초 위치할 시작 위치를 설정할 수 있습니다.
setHomePosition 후에는 반드시 updateHomePosition 함수를 호출하여 정보를 갱신해야합니다.
U3dAPP.setHomePosition(geox, geoy, height, rotateleft, rotatedown);
geoxnumber : 위경도 x값 (경도)
geoynumber : 위경도 y값 (위도)
heightnumber : 고도
rotateleftnumber : 방위각 (좌우각)
rotatedownnumber : 고도각 (상하각)
// 경도 : 126.4407, 위도: 37.4602, 고도: 700, 방위각 : 2, 고도각 : 60 app.setHomePosition(126.4407, 37.4602, 700, 2, 60); app.updateHomePosition(); // setHomePosition 후에 필수로 호출해야함 !!!
