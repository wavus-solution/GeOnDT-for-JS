3D 자료 변환 및 레이어 발행

모델이나 이미지 파일을 업로드하거나 레이어를 발행하는 예제입니다.
레벨이나 좌표계, 품질 등 레이어 발행 정보를 지정할 수 있고, 업로드의 진행 상태를 확인하는 기능도 포함합니다. 

업로드 파일 타일링 스케쥴 예제
        1. 업로드 파일의 타입 선택(건물/고도)합니다.
        2. 타일링 설정 정보를 입력합니다.
        3. 업로드할 파일을 선택합니다.
        4. 발행버튼을 클릭합니다.
        5. 발행된 레이어에 보기 버튼을 클릭하면 서버에 발행된 레이어서 APP에 생성됩니다.
        6. 이동버튼을 클릭하면 APP에 생성된 레이어의 위치로 이동합니다.
