해상도 제어 예제

선택한 모델의 해상도를 제어하는 예제입니다.
전체 해상도를 제어하거나, 원하는 하위 Layer만 선택해 해상도를 제어할수 있습니다. 

        
        1. Model Layer 선택
            1) 초기 Model Layer는 U3F Model 입니다.
            2) 해당 항목 선택시 이전 Model Layer를 지우고 다시 그려줍니다.

        2. 전체 해상도 선택
            1) 초기값은 기본모드로 해상도 제어가 되지 않은 초기 상태 입니다.
            2) 전체 해상도 제어로 하위 지역 Layer의 해상도도 같이 제어합니다.
            3) 고해상도 모드 선택시 높은 해상도의 텍스쳐 이미지만 출력합니다.
                저해상도 모드 선택시 낮은 해상도의 텍스쳐 이미지만 출력합니다.

        3. 하위 Layer 선택 후 이동 및 해상도 제어
            1) U3F Model Layer 선택시 하위 Layer 목록이 추가됩니다.
            2) 해당 하위 지역 Layer의 해상도만 제어 가능 하며, 이동 버튼 클릭시 해당 지역으로 이동합니다.
