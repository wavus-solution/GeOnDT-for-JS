평균 높이 분석

건물 모델을 선택하고 선택한 객체들의 평균 높이를 계산합니다.

모델 선택

클릭 선택은 Shift로 추가합니다. 다각형은 세 지점 이상을 클릭하고 더블클릭으로 마칩니다.

평균 높이 (월드 Z)

—

월드 좌표(EPSG:3857)의 Z축 경계 길이입니다. 실제 지상 높이 환산값이 아닙니다. 선택을 변경하면 다시 계산하세요.

선택 객체 0개

선택된 모델이 없습니다.

객체 번호를 펼치면 전체 식별값을 확인할 수 있습니다.

선택한 모델과 월드 Z축 높이
선택 객체높이 (월드 Z, m)

건물이 보이지 않으면 모델 데이터 서버 연결과 확대 수준을 확인하세요. U3F 병합 모델은 개별 건물로 분리해 선택합니다.
