: SHP 사용자 텍스처 모델 레이어

Shp 파일을 업로드하여 3D 모델을 생성하는 레이어 예제입니다.
텍스처 지정 함수(multiSideFunction)를 통해 사용자가 모델의 각 면마다 원하는 텍스처를 지정할 수 있습니다. 

지도상에 설계건물(shp 파일)을 추가할 수 있습니다.
        1. textureList에 배열 형대로 사용할 사용자 텍스처를 저장합니다.
        2. shp 블러오기 버튼으로 저장된 shp 파일을 읽어옵니다.
        3. U3dModelShapeLayer 생성 시 styleFunction return 옵션으로 multipleTexture: true 와 multiSideFunction 함수를 지정합니다.
        4. multiSideFunction은 파라미터로 (mesh, vertices ,width)를 받습니다. 해당 파라미터를 기준으로 사용자가 생성된 3D모델을 다양한 텍스처로 스타일링 할수 있습니다.
