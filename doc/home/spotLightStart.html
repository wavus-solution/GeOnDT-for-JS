1. 시작하기

광원 클래스 USpotLight는 지도 상에 원뿔형 SpotLight를 생성하는 클래스입니다.
커스텀 광원의 생성·편집을 지원하며, 광원 범위(가시 영역) 분석 기능을 포함합니다.
USpotLight (opt)
opt.namestring : 광원 이름
opt.drawArgUDrawArg : 그리기 클래스
opt.positionGeoPosition : 광원 위치
opt.leftnumber : 광원 좌우 각도
opt.upnumber : 광원 상하 각도
opt.intensitynumber : 광원 세기
opt.anglenumber : 광원이 분산되는 최대 각도 (광원 사이각)
opt.distancenumber : 광원 최대 거리
opt.colornumber : 광원 색
opt.groundGapnumber : 광원과 지면 사이 거리
opt.useHelperObjboolean : 픽킹/편집용 가이드 객체 사용 여부
opt.objRadiusnumber : 가이드 객체 반지름
const position = {x: 126.9404, y: 37.5183, z: 12}; // 광원 생성 const light = new GeOnDT.view.USpotLight({ name: '가로등_1', drawArg: app._drawArg, left: 0, up: 90, position: position, color: 0xffffff, groundGap: 20, useHelperObj: true, angle : 90, intensity: 10, distance: 1000, objRadius: 8 }); // 광원 app에 등록 app.addLight(light);

2. 조회하기

광원 클래스 USpotLight는 지도 상에 원뿔형 SpotLight를 생성하는 클래스입니다. 커스텀 광원의 생성·편집을 지원하며, 광원 범위(가시 영역) 분석 기능을 포함합니다.
U3dView.findLightByName(name) : 광원 이름으로 특정 광원을 조회하는 함수
namestring : 광원 이름
return USpotLight : 광원
U3dView.getLightList(degLeft) : 전체 광원 목록을 조회하는 함수
degLeftDegree : 카메라 뷰 좌우 각
return USpotLight [] : 전체 광원 목록
const name = '가로등_1'; const light = app.findLightByName(name); //또는 const lightList = app.getLightList(); const find = lightList.find((light) =>{ return light.name === name; });

3. 위치·회전 편집하기

광원의 위치·회전를 편집하는 방법은 두 가지가 있습니다.
하나는 USpotLight 클래스에서 제공하는 편집 관련 API를 사용하는 방법이며, 다른 하나는 Gizmo 툴을 사용해 조작하는 방법입니다.

먼저 USpotLight 클래스에서 제공하는 편집 관련 API를 알아보겠습니다.
USpotLight.setRotationUp(degUp) : 광원 상하 각도를 상하 각을 편집하는 함수 (회전 편집)
degUpDegree : 광원 상하 각도 (수직각)
USpotLight.setRotationLeft(degLeft) : 광원 좌우 각도를 편집하는 함수 (회전 편집)
degLeftDegree : 광원 좌우 각도 (수평각)
USpotLight.setPosition(position) : 광원 위치를 편집하는 함수 (위치 편집)
positionWorldPosition : 이동할 위치 좌표 (3D월드 좌표)
const light = app.findLightByName('가로등_1'); // 회전 편집 light.setRotationLeft(20); light.setRotationUp(50); // 위치 편집 const position = {x: -211992.9599, y: 103254.0005, z: 17}; light.setPosition(position);
Gizmo 툴은 USpotLight.edit API를 통해 활성화합니다.
Gizmo 툴을 사용하려면 기준점 역할을 하는 가이드 객체(HelperObject)가 반드시 필요합니다.

useHelperObj 옵션은 기본값이 true이며, 해당 옵션이 비활성화되어 있는 경우에는 광원 생성 시 useHelperObj: true 옵션을 명시적으로 지정해 주세요.
가이드 객체(HelperObject)는 필요에 따라 가시성을 제어할수 있습니다.
USpotLight.edit(state, mode) : 광원에 Gizmo를 추가해 편집하는 함수
stateboolean : 작업 상태 (true면 gizmo ON, false면 gizmo OFF)
modestring : 편집 모드 (translate, rotate)
USpotLight.reset() : 편집한 위치·회전 초기화 함수
USpotLight.showControlObj() :광원 가이드 객체 (helperObject)를 켜는(show)하는 함수
USpotLight.hideControlObj() : 광원 가이드 객체 (helperObject)를 끄는(hide)하는 함수
const light = app.findLightByName('가로등_1'); light.edit(true, 'translate'); // 이동 편집 모드 light.edit(true, 'rotate'); // 회전 편집 모드 light.edit(false); // 편집 종료 light.reset(); // 편집 초기화

4. 광원 설정하기

광원 설정 API를 통해 광원의 세기(Intensity), 최대 거리(Far), 각도(Angle), 색상, 가시선 표시 여부를 설정할 수 있습니다.
세기(Intensity)는 광원의 밝기 강도를 의미합니다.
값이 클수록 빛이 강해지며, 조사되는 영역이 더 밝게 표현됩니다.
USpotLight.setIntensity(intensity) : 광원 세기를 설정하는 함수
intensitynumber : 광원 세기
const light = app.findLightByName('가로등_1'); light.setIntensity(5); // 광원 세기 5 설정
최대 거리(Far)는 광원이 영향을 미치는 최대 거리를 의미합니다.
설정된 거리보다 먼 영역에는 빛의 영향이 적용되지 않습니다.
USpotLight.setDistance(distance) : 광원 최대 거리를 설정하는 함수
distancenumber : 광원 최대 거리
const light = app.findLightByName('가로등_1'); light.setDistance(1000); // 1km 이상은 광원 영향 X
각도(Angle)는 광원이 퍼지는 조사 각도(확산 범위) 를 의미합니다.
값이 클수록 넓은 영역을 비추고, 작을수록 집중된 빛을 형성합니다.
USpotLight.setAngle(angle) : 광원 조사 각도를 설정하는 함수
anglenumber : 광원 조사 각도
const light = app.findLightByName('가로등_1'); light.setAngle(50);
USpotLight.setColor(color) : 광원 색상을 설정하는 함수.
colorColor : 광원 색상
const light = app.findLightByName('가로등_1'); light.setColor("#fff000"); // 노란색으로 설정
가시선은 광원의 방향, 각도, 최대 거리를 3D 공간에 시각적으로 표현해주는 보조선입니다.
광원이 실제로 비추는 범위를 직관적으로 확인 가능합니다.
USpotLight.setAngle(angle) : 광원 가시선을 설정하는 함수.
anglenumber : 광원 가시선 가시화 여부 (true면 켜고, false면 끈다.)
const light = app.findLightByName('가로등_1'); light.showHelper(true); // 가시선 켜기 light.showHelper(false); // 가시선 끄기

5. 광원 분석하기

광원의 조사 범위를 분석하여, 건물과의 차폐·충돌 여부 및 실제로 광원이 도달하는 공간을 3D 객체로 가시화할 수 있습니다.
광원 분석은 USpotLight.analysisLight API를 사용해 수행합니다.

파라미터 옵션의 type 값은 cone과 viewCone 두 가지로 설정할 수 있습니다.
viewCone은 콘 형태의 높이가 없는 평면 Mesh(2D) 로 생성되며, cone은 높이를 가진 콘 형태의 Mesh(3D) 로 생성됩니다.
USpotLight.analysisLight(opt) : 광원 범위를 분석하는 함수
optobject : 분석 객체 생성 옵션
opt.colorColor : 객체 색상
opt.opacitynumber : 객체 투명도
opt.typestring : 객체 타입 (cone, viewCone)
opt.azimuthnumber : 객체 방위각 (수평각)
opt.distancenumber : 객체 최대 거리(far)
opt.startOffsetnumber : 객체 시작 거리 (카메라 뷰와 객체 사이의 거리)
const light = app.findLightByName('가로등_1'); // 광원 분석 실행 light.analysisLight({ type: 'cone', color: "#fff000", opacity: 0.5, azimuth: 90, distance: 1000, startOffset : 10 }).then(()=>{ console.log('분석 성공!'); }).catch((e)=>{ console.error('분석 실패!'); });

6. 제거하기

광원을 제거하는 방법은 U3dApp 클래스의 제거 API를 사용하는 것입니다.
removeLight(light) API는 파라미터로 입력 받은 특정 광원을 제거하고, removeAllLight() API는 등록된 전체 광원을 제거합니다.
U3dApp.removeLight(light) : 파라미터로 입력 받은 광원을 제거하는 함수
lightUSpotLight : 제거할 광원
U3dApp.removeAllLight() : 전체 광원을 제거하는 함수
또는 직접 USpotLight에 접근해 remove() API를 호출해 제거할 수 있습니다.
USpotLight.remove() : 광원 제거 함수
// 특정 광원 제거 const light = app.findLightByName('가로등_1'); app.removeLight(light); // 전체 제거 app.removeAllLight(); //또는 직접 순회하면서 제거 const list = app.getLightList(); for(const light of list) { light.remove(); }
