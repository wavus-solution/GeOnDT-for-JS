주행모드 예제

입력한 좌표로 이동하여 사용자의 조작에 따라 모의주행을 시뮬레이션하는 예제입니다.
사용자 주행 버튼을 누르고 마우스 이동 및 키보드 조작으로 해당 자동차 모델을 이동하며 모의 주행 할수 있습니다.
사이드미러, 백미러의 가시화 상태를 변경 하거나 화면 전환을 통해 여러 방면에서 확인 할수 있습니다. 

        * 사용자 주행 모드 : 사용자의 조작으로 차량 주행 기능

            1. 사용자 주행 모드
                - 설정한 위치로 이동하여 주행모드를 시작합니다.
                - Q || E || F 키보드 입력으로 LEFT || RIGHT || BACK 사이드 미러를 가시화를 조작할 수 있습니다.
                - 화면전환 // 'C' 키보드 입력으로 카메라 위치를 자동차를 바라보는 위치로 복귀합니다.
                - 카메라 고정 // 'H' 키보드 입력으로 카메라 위치를 고정하여 조작할 수 있습니다.

            2. 지도 모드
                - 지도 모드로 설정합니다.
                - 주행 모드에서 지도모드로 화면전환 됩니다.

            3. 사이드 / 백미러 on off
                - 가시화를 원하는 거울의 체크박스를 선택하여 가시화를 조작할수 있습니다.
                - 주행 모드시 키보드 입력으로 전환 가능합니다. ( Q - LEFT, E - RIGHT, F - BACK )
