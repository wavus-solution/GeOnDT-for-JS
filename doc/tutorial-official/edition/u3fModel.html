U3F 모델 레이어

U3F 모델 레이어

3D 모델 레이어 중, U3F 2.2V·2.3V·2.4V·2.5V 모델 레이어를 버전별로 화면에 출력하는 예제입니다. 각 체크박스는 독립적으로 동작하므로 여러 버전을 동시에 비교할 수 있습니다.

  • 2.2V: category=korea 서버의 발행 중인 레이어
  • 2.3V: category=AL_D198 서버의 공유 재질 레이어
  • 2.4V: model-2.4/seoul U3G 레이어 묶음
  • 2.5V: model-2.5/seoul U3G 레이어 묶음

코드 편집은 데스크톱 환경에서 지원합니다.

더 넓은 화면에서 Editor를 열거나 지도 Viewer로 돌아가세요.

실행 전에는 × 닫기와 가장자리 ◀ 버튼으로 지도로 돌아갑니다.
실행한 뒤에는 같은 버튼이 편집 패널만 접고, 실행한 화면은 그대로 남습니다. 접으면 왼쪽 가장자리 ▶로 다시 펼칩니다.
