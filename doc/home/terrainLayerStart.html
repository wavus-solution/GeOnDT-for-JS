1. 시작하기

* TerrainLayer를 시작하기 위해서 우선 생성 옵션 값이 필요합니다. 옵션 값의 자세한 내용은 API 페이지의 TerrainLayer 카테고리를 참고해 주세요.
* 생성 옵션 값 중 baseurl, ext(.umf) 는 꼭 넣어 줘야하는 필수 옵션 값입니다.
const option = { name: 'korea_terrain', // 레이어 이름 baseurl: 'https://dt-data.mappick.co.kr/ServiceData/dem/DEM_CS/Korean_peninsula/', // 고도 데이터 URL *필수 입력 ext: '.umf', // 파일 확장자, *필수 입력 reverseY: true, // X축 반전 여부, default false minlevel: 9, // 가시화 최소 레벨, default 0 maxlevel: 17, // 가시화 최대 레벨, default 19 useproxy: false, // 프록시 사용 여부, default false }
* TerrainLayer는 app.createHeightXYZLayer(opt) 함수를 호출하여 생성합니다.
const layer = app.createHeightXYZLayer(option);
* 모든 레이어 객체는 생성 후 .ready() 또는 .then() 을 포함하는 promise 함수를 지원합니다. 해당 함수를 이용해 후처리를 수행할 수 있습니다.
layer.ready(() => { console.log(name + " create success."); }).then(() => { console.log(name + " create success."); }).catch(function (e) { console.error("work fail : " + e); }).finally(() => { console.log(name + " create end."); });
* 생성된 레이어는 app.showLayer(layername, true/false) 함수를 통해 가시화/비가시화가 가능합니다.
layer.ready(() => { app.showLayer(name, true).then(()=>{ console.log(name + " show."); }); }).catch(function (e) { console.error("work fail : " + e); });
