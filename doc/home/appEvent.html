1. 이벤트 추가 및 제거

이벤트를 추가 할 때는 U3dApp 클래스 on 함수를 사용합니다.
이벤트를 제거 할 때는 U3dApp 클래스 unkey 함수를 쓰는 방법과 off 함수를 쓰는 방법 두 가지가 있습니다.

unkey 함수는 이벤트 고유 ID를 통해 명시적으로 이벤트를 제거합니다.
off 함수를 통해 이벤트를 제거할 경우 익명 함수나 bind 함수인 경우 제대로 제거되지 않을 수 있으므로, unkey 함수를 통해 제거하는 것을 권장합니다.
U3dApp.on(eventName, eventCallback) : 이벤트 추가 API
eventNamestring : 이벤트 이름
eventCallbackvector : 이벤트 콜백 함수
U3dApp.off(eventName, eventCallback) : 이벤트 제거 API
eventNamestring : 이벤트 이름
eventCallbackstring : 이벤트 콜백 함수
U3dApp.unkey(eventName, eventID) : 이벤트 명시적 제거 API
eventNamestring : 이벤트 이름
eventIDstring : 이벤트 고유 ID
// 이벤트 추가 밑 ID 저장 const eventID = app.on('click', eventCallBack); app.unkey('app-load', eventID); //또는 app.off('app-load', eventCallBack);

2. APP LOAD & LOADED 이벤트

'app-load' 이벤트는 화면상에 모든 레이어 표출이 시작될 때 발생합니다.
'app-loaded' 이벤트는 화면상에 모든 레이어 표출이 종료될 때 발생합니다.
// 화면상에 모든 레이어 표출이 시작될 때 발생 const loadEventID = app.on('app-load', startEventCallBack); app.unkey('app-load', loadEventID); // 화면상에 모든 레이어 표출이 종료될 때 발생 const loadedEventID = app.on('app-loaded', endEventCallBack); app.unkey('app-loaded', loadedEventID);

3. APP SEARCHED 이벤트

'app-searched' 이벤트는 카메라 프러스텀(가시범위)에 포함되는 타일을 검색 완료 했을 때 호출되는 이벤트 입니다.
const searchedEventID = app.on('app-searched', searchedEvent); app.unkey('app-searched', searchedEventID);

4. APP MEMORY CLEAR 이벤트

'app-memory-clear' 이벤트는 불필요한 자원(가시화가 해제된 타일이나 사용하지 않는 캐시 등...)을 메모리를 정리할 때 호출되는 이벤트 입니다.
const clearEventID = app.on('app-memory-clear', clearEvent); app.unkey('app-memory-clear', clearEventID);

5. UI 관련 이벤트

화면 이동이나 클릭같은 UI 이벤트를 app에 등록하여 사용할 수 있습니다.
app.on('change', changeEvent); ** 화면 이동 시 발생 app.on('click', clickEvent); ** 클릭 시 발생 app.on('dblclick', dblclickEvent); ** 더블클릭 시 발생 app.on('mousewheel', mousewheelEvent); ** 마우스 휠 조작 시 발생 app.on('mousemove', mousemoveEvent); ** 마우스 이동 시 발생 app.on('mousedown', mousedownEvent); ** 마우스를 누를 때 발생 app.on('mouseup', mouseupEvent); ** 마우스를 뗄 때 발생 app.on('mouseout', mouseoutEvent); ** 화면 밖으로 마우스 이동 발생 app.on('resize', resizeEvent); ** 화면 크기 변경시 발생
