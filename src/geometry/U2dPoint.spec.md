# U2dPoint 명세

> 상태: 구현 관찰 초안

## 목적과 책임

OpenLayers의 점 형상과 원형 스타일을 공통 도형 인터페이스로 편집한다. 복합 점 원본을 연결하면 각 점의 형상을 보존한다.

## 공개 계약

- 기본 생성자는 반지름 5와 채움·외곽선 스타일을 준비한다. `createGeometry()`는 최초 점 geometry를 준비한다. `sourceFeature` 경로는 기존 Point·MultiPoint와 원형 스타일을 보존하며 기본 Circle과 캔버스는 첫 `getStyle()`까지 만들지 않는다. 위치 이동이나 같은 반지름·색·두께 재설정으로 원형 캔버스를 다시 만들지 않는다.
- `setPosition()`은 단일 점 또는 점 목록을 받으며 기본 입력 좌표계는 EPSG:4326이다. 내부 좌표는 EPSG:3857이다. 점 목록은 MultiPoint로 보존한다.
- `setFeature()`는 원본 형상과 스타일을 보존하고, 원형 이미지가 있으면 그 이미지와 반지름을 사용한다. 내부 생성 원본의 해제 책임을 넘기는 선택 인자도 기반 클래스에 전달한다.
- `setRadius()`는 편의 필드와 원형 이미지의 반지름을 함께 변경하여 원본 변경을 통지한다. 이후 색상·두께 수정으로 반지름이 이전 값으로 되돌아가지 않는다.
- 반경 0은 생성·setParam·setRadius에서 유지하며 표시 좌표·정적 terrain payload·검색 반경도 0을 사용한다. 기본 반경이나 양수 최소값으로 바꾸지 않는다.
- `getRadius()`는 현재 원본 원형 이미지의 반지름을 읽고 이미지가 없으면 편의 필드를 반환한다. `getParam()`은 공통 항목과 반지름을 반환하며 `setParam()`은 모든 값의 검증 후 부분 적용한다. MultiPoint의 반경과 스타일은 점별이 아닌 객체 전체의 공통 값이다. `setParam()`은 스타일 잠금 중 반경도 변경하지 않는다. 기존 `setRadius()`의 직접 호출 계약은 유지한다.
- `getStyle()`은 원본 원형 이미지의 반지름·채움·외곽선과 편의 필드를 함께 동기화한다. `setFeature()`·`setStyle()`도 같은 동기화 경로를 사용한다. 외부에서 교체한 원형 스타일에도 후속 편집이 적용되며, 채움·외곽선이 없는 원형 이미지는 해당 항목의 명시적 편집 시 도형의 스타일을 연결한다.
- `setStyle()`·채움색·외곽선색·두께 변경은 공통 도형 동작과 원형 이미지를 함께 갱신한다. 스타일 잠금 상태에서 `setStyle()`은 변경하지 않는다.
- 반지름의 지형 표시 단위 변환과 동적 반지름은 레이어에서 처리한다. 점 사이를 잇는 큰 원으로 복합 점을 검색하지 않는다.

## 검증

`tests/geometry/vector-binding.test.mjs`에서 반지름 유지, 복합 점의 생성·표시 조각·검색을 확인한다. 반지름의 실제 화면 픽셀 크기는 지도 통합 검증 대상이다.
