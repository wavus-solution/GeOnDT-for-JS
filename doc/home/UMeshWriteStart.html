1. UMeshWriter 생성하기

* UMesh 파일을 쓰기 위해선 일단 UMeshWriter를 생성해야합니다.
GeonDT.writer.UMeshWriter({opt});
opt.app U3dApp : 사용할 app
const writer = new GeonDT.writer.UMeshWriter({ app: u3dApp });

2. UMeshWriter 준비하기

* 파일로 내보길 원하는 UMesh 객체 정보를 UMeshWriter가 인식할 수 있도록 writer 데이터를 생성해야합니다. (예제코드 확인)
* UMeshWriter는 데이터 객체를 배열로 받아 umesh 포멧 파일로 생성합니다.
const meshes = []; modelList.forEach((model)=>{ const meshMap = {}; const items = []; meshMap.type = "mesh" //일반 umesh 추가 // meshMap.type = "instanceMesh" //instance mesh 추가 meshMap.name = "UMesh_" + idx; model.traverse((child)=>{ if(child.isMesh) items.push(child) }); meshMap.items = items; meshes.push(meshMap); });
* 추가적으로 imageFlipY 등 파일 생성에 관한 옵션을 필요에 따라 설정할 수 있습니다.
let writeInfo = { imageFlipY : imageFlipY }
* 만약 일반 UMesh가 아닌 Instance Mesh를 쓰려고 한다면, Instance Mesh 정보를 담은 파라미터를 추가로 넣어야 합니다.
// Instance Mesh 정보 리스트 instanceInfo = [ { name : "instance_1", resourceName : "UMesh_0", position : {x: 127.132, y: 37.380, z: 84}, rotation : {x: 0, y: 0, z: 0}, scale : {x: 1, y: 1, z: 1} }, { name : "instance_2", resourceName : "UMesh_0", position : {x: 127.133, y: 37.381, z: 84}, rotation : {x: 0, y: 0, z: 0}, scale : {x: 1, y: 1, z: 1} } ]

3. UMesh 파일 쓰기

* UMesh 파일을 쓰기 위해선 일단 UMeshWriter를 생성해야합니다.
GeonDT.writer.UMeshWriter({opt});
opt.app U3dApp : 사용할 app
const writer = new GeonDT.writer.UMeshWriter({ app: u3dApp }); writer.write(meshes, writeInfo, instanceInfo).then((data) =>{ const umeshBlob = data.umesh; const fileName = 'GeOnDT_file.umesh'; const umeshBlobUrl = URL.createObjectURL(umeshBlob); downLoadBlob(fileName, umeshBlobUrl); const resourceList = data.resource; for(let resource of resourceList) { fileName = item.name; resourceBlobUrl = URL.createObjectURL(item.blob); downLoadBlob(fileName, resourceBlobUrl); } });
