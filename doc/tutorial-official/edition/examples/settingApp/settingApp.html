  - 지형 및 고도 처리 방법으로, 스커트 생성 방식을 결정하는 옵션. (지하 시설물이 존재하는 경우 1_0 권장)
   1) raw : default한 방법으로, 상대적인 값을 빼거나 더해 스커트를 생성하는 방식.
      * base 방식을 개선한 것으로 base보다 스커트 처리 속도는 느리지만 품질은 향상되었다.
   2) base : 스커트를 무조건 0으로 계산하여 생성하는 방식.
      * 스커트 처리 속도가 빠르지만 지하시설물이 존재하는 경우 사용을 권장하지 않는다.
   3) 1_0 : 가장 최신 기법. 동적으로 스커트를 연산 하여 지하시설물이 스커트로인해 가려지지 않도록 하는 방식.
      * 스커트 처리 속도는 가장 느리지만 지하시설물이 존재하는 경우 사용이 권장된다.

 - 카메라 시점 주위의 타일을 검색하는 방식. (타일 랜더링 속도에 영향)
   1) sphere : 카메라를 기준으로 가상의 Sphere 생성하여 교차되는 타일을 검색.
    * boundingbox 방식에 비해 처리 속도는 느리지만, 타일 생성은 보다 정교함
   2) boundingbox : default한 방법으로, 카메라를 기준으로 가상의 Box를 생성 하여 교차되는 타일을 검색.
